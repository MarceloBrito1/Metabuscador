# Metabuscador

A **Metabuscador** (Metasearch Engine) is a tool that aggregates search results from multiple search engines into a single, unified interface. Instead of querying one search engine at a time, it queries several simultaneously and presents the combined results to the user.

## Features

- Queries multiple search engines in parallel
- Aggregates and deduplicates results
- Provides a unified search experience
- Fast and efficient result retrieval

## How It Works

1. The user submits a search query through the Metabuscador interface.
2. The engine forwards the query to multiple configured search providers simultaneously.
3. Results from all providers are collected, merged, and ranked.
4. The final unified result set is displayed to the user.
